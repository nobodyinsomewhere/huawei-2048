# 2048 · 专属小游戏

一个完整的 2048 小游戏，全部代码写进单个 `index.html`，不依赖任何框架、构建工具或网络资源，双击文件就能玩。

## 玩法

- 电脑：方向键或 WASD 移动方块，相同数字相撞合体
- 手机：在棋盘上滑动屏幕
- 目标是合出 2048，达到后仍可继续挑战更高分

## 实现说明

棋盘用一个 4×4 二维数组表示，每次操作分三步：先按方向压缩，再把相邻相同数字合并并累加分数，最后补齐空位。同时随机在空位生成 2 或 4，并记录历史局面，支持无限撤销。

渲染直接操作 DOM，用 CSS 变量控制不同数字的配色，方块的出现与合并带过渡动画。触摸事件与键盘事件共用同一套逻辑，所以手机和电脑体验一致。

## 部署过程

这个页面先用 AI Agent 生成，部署到华为云沙箱做公网预览，再用 ECS 加 Nginx 托管，页面放在 `/hc-activity/index.html`，对外公开访问。
